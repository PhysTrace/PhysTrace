The MLLM is called once per window and returns state captions, prediction captions and whether to trust the window (trusted). Physics-error candidates are the k windows with the lowest CLIP score (this window's prediction ↔ this window's video); trusted only decides whether a window enters the history.

MLLM prediction & window settings

  • MLLM frames: frames per window (even numbers only)
  • CLIP frames: 0 = every frame; changing it reloads CLIP
  • n: captions per field
  • History: latest trusted windows kept
  • k: lowest-CLIP windows shown as error candidates (0 = none)
  • Output limit: max tokens per window, thinking + answer (max –)
  • Thinking budget: cut-off for thinking, below the output limit

The output format (state / prediction caption lists, trusted) and the trusted rule are in the system prompt.
